# Random Search for Hyper-Parameter Optimization — Bergstra & Bengio, 2012

Shows random search beats grid search at equal budget.

The argument is geometric and immediately convincing: only a few
hyperparameters usually matter, and a grid wastes its budget evaluating the same
few values of the important ones repeatedly while random sampling explores many.

One of the highest ratios of practical value to conceptual difficulty in this
whole reading list.
