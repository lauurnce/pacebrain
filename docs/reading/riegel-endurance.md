# Athletic Records and Human Endurance — Riegel, 1981

Fits the relation `T2 = T1 * (D2/D1)^b` across athletic records and finds an
exponent near 1.06 for running.

Two constraints on using it that the formula's popularity tends to obscure: it
needs an actual race performance as input, not a training pace, and the exponent
is a population fit — an individual's speed-endurance balance can sit well away
from it.

Directly relevant as the non-ML baseline for this project.
