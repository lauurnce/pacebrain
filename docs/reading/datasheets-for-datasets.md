# Datasheets for Datasets — Gebru et al., 2018

The dataset counterpart to model cards: motivation, composition, collection
process, preprocessing, and recommended uses.

The argument is that most model failures trace to properties of the data that
nobody wrote down, so the documentation gap is upstream of the model.

Reading it changed how I think about the synthetic data here — a generator is a
dataset with a fully known datasheet, which is exactly why results on it
describe the code and not the world.
