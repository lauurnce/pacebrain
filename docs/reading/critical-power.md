# Critical power and the power-duration curve

Models sustainable intensity as an asymptote, with a finite work capacity
available above it that depletes and recovers.

More physiologically grounded than percentage-of-maximum zones because it is
derived from performance rather than assumed from a maximum, and it predicts
the interval-recovery structure rather than being fitted to it.

The obvious candidate if this project ever moves from finish time to pacing
within a race.
