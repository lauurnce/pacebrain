# Reconciling Modern Machine Learning and the Bias-Variance Trade-off — Belkin et al., 2019

Documents the double descent curve: test error rises toward the interpolation
threshold, then falls again as capacity grows past it.

Reconciles the classical U-shaped tradeoff with the observation that enormous
models work — the classical picture is the left half of a larger curve.

Changes the practical instinct. "The model is too big" is not automatically the
diagnosis for poor test error; it may be not big enough.
