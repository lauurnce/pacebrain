# Model Cards for Model Reporting — Mitchell et al., 2019

Proposes a standard short document accompanying a model: intended use,
out-of-scope use, training data, evaluation broken down by relevant groups, and
limitations.

The disaggregated evaluation is the substantive part. Aggregate accuracy hides
subgroup failure, and the card format forces the breakdown to exist.

Adopted this for the project directly — a page, but it forces the question of
what you would have to admit if someone relied on the thing.
