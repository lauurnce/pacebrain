# Daniels' Running Formula — Jack Daniels

Builds training prescription around VDOT, a single number derived from a race
performance that maps to equivalent performances and to paces for each training
intensity.

The strength is that it is anchored to something measured rather than to a
percentage of an estimated maximum, and the intensity categories are defined by
physiological purpose rather than by feel.

The limitation is the same one Riegel has: the equivalences are population
regressions, so a runner whose speed-endurance balance is unusual gets
systematically misprescribed at one end. Useful as a starting point that expects
to be adjusted, which is roughly how any model here should be treated.
