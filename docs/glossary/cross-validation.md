# Cross-validation

Splitting data into k folds and training k times, each fold serving once as validation. It gives a more stable estimate than one holdout and, just as usefully, a spread across folds that says how much any single split could have misled you.

Cross validation interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
