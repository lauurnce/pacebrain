# Plyometrics

Explosive jumping work training the stretch-shortening cycle of the tendons. It improves economy by making each stride return more elastic energy, and it carries a real injury cost if volume is added quickly.

Plyometrics interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
