# Carb loading

Raising carbohydrate intake in the days before a long race to maximise [[glycogen]] stores at the start. It only pays off for efforts long enough to deplete them, so it does nothing useful before a 5 km and costs a little extra water weight.

- [Negative split](negative-split.md)

Carb loading interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
