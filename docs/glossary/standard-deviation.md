# Standard deviation

The square root of [[variance]], returning the measure to the units of the data. That is its only advantage and it is a large one, since a spread expressed in minutes is interpretable where minutes-squared is not.

## See also

- [Correlation](correlation.md)
- [Variance](variance.md)

Standard deviation interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
