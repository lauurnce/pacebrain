# Activation function

A nonlinearity applied between layers, such as ReLU, sigmoid or tanh. Without one a stack of linear layers collapses algebraically into a single linear layer, so the activation is the entire reason depth buys anything.

In PaceBrain, Activation function matters at exactly the boundary between baselines and fancier models — it is one of the knobs that decides whether added complexity earns its keep.
