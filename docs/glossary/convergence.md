# Convergence

The point at which further training stops meaningfully improving the objective. Worth distinguishing from a good result: a model can converge reliably to a bad solution, and a flat loss curve says the optimiser has stopped moving, not that the model is right.

The failure mode to watch with Convergence is silent optimism: results improve on the validation set for reasons that will not survive contact with next month's data.
