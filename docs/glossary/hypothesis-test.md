# Hypothesis test

A procedure for deciding whether observed data is consistent with a stated null hypothesis. Its output is a decision under an error rate, not a measure of effect size — a result can be significant and far too small to matter.

Hypothesis test interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
