# Likelihood

The probability of the observed data viewed as a function of the parameters rather than of the data. The reversal is the whole point: probability asks what data a model produces, likelihood asks which model the data supports.

The failure mode to watch with Likelihood is silent optimism: results improve on the validation set for reasons that will not survive contact with next month's data.
