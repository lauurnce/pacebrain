# Running economy

How much oxygen a runner uses to hold a given submaximal pace — the efficiency counterpart to [[vo2max]]'s ceiling. Two runners with identical VO2 max can differ substantially in race performance because of it, which is why a single fitness number predicts finish times poorly.

- [Supercompensation](supercompensation.md)
- [Stress fracture](stress-fracture.md)

In PaceBrain terms, Running economy shows up whenever weekly logs are turned into features — the textbook definition is crisp, real training data is not, and the gap is where the modelling lives.
