# Running economy

How much oxygen a runner uses to hold a given submaximal pace — the efficiency counterpart to [[vo2max]]'s ceiling. Two runners with identical VO2 max can differ substantially in race performance because of it, which is why a single fitness number predicts finish times poorly.
