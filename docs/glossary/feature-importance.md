# Feature importance

Any score ranking how much each input contributes to predictions. Worth treating cautiously: most methods are unreliable under correlated features, splitting credit between them in ways that look like evidence and are not.

The failure mode to watch with Feature importance is silent optimism: results improve on the validation set for reasons that will not survive contact with next month's data.
