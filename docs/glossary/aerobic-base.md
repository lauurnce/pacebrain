# Aerobic base

The endurance foundation built by sustained easy running. Largely a function of total weekly volume accumulated over months, and the strongest single predictor of performance at distances beyond 10 km.

## See also

- [Steady state](steady-state.md)

Aerobic base interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
