# Bias-variance tradeoff

The decomposition of expected error into bias (systematic wrongness from too simple a model), variance (sensitivity to which training sample was drawn) and irreducible noise. Its practical value is diagnostic rather than numerical: it says whether to reach for more capacity or more data, and those are opposite responses to what looks like the same bad score.

The failure mode to watch with Bias variance tradeoff is silent optimism: results improve on the validation set for reasons that will not survive contact with next month's data.
