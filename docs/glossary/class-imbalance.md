# Class imbalance

When one class vastly outnumbers others, so a model predicting only the majority scores well on accuracy while being useless. It is primarily a metric problem rather than a data problem — the fix starts with scoring against something that notices, such as recall or a per-class breakdown.

Class imbalance interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
