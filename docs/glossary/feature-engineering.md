# Feature engineering

Transforming raw inputs into representations that make the target easier to learn — ratios, logs, interactions, aggregates. It substitutes knowledge about the problem for model capacity, which is often the better trade: the right transform can beat a larger model outright, and does so deterministically.

In PaceBrain, Feature engineering matters at exactly the boundary between baselines and fancier models — it is one of the knobs that decides whether added complexity earns its keep.
