# Splits

The times recorded for each segment of a race, usually per kilometre or mile. Their pattern is more informative than the finish time alone: an even set and a fading set can total the same while describing completely different races.

In PaceBrain terms, Splits shows up whenever weekly logs are turned into features — the textbook definition is crisp, real training data is not, and the gap is where the modelling lives.
