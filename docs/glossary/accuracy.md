# Accuracy

The fraction of predictions that are correct. Nearly useless under [[class-imbalance]], where predicting the majority class alone can score highly while the model has learned nothing.

Accuracy interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
