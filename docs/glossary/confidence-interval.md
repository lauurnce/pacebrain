# Confidence interval

A range constructed so that, over repeated sampling, a stated proportion of such intervals contain the true value. The guarantee is about the procedure rather than any single interval, which is the part routinely misread.

## See also

- [Central limit theorem](central-limit-theorem.md)

Confidence interval interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
