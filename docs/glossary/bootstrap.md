# Bootstrap

Estimating the sampling distribution of a statistic by resampling the observed data with replacement. It gives confidence intervals for quantities with no clean closed form, which covers most things worth measuring.

The failure mode to watch with Bootstrap is silent optimism: results improve on the validation set for reasons that will not survive contact with next month's data.
