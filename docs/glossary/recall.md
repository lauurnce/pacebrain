# Recall

Of everything that genuinely was positive, the fraction the model found. The metric to optimise when a missed case is the expensive error, and it trades directly against [[precision]]: predicting positive more often raises one and lowers the other.

Recall interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
