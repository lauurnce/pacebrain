# Linear regression

Fitting a weighted sum of features by least squares, with a closed-form solution. Its value as a reference point outlives its value as a model — anything more complex should have to beat it before its complexity is justified.

Linear regression interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
