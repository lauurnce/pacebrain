# Cadence

Steps per minute. Often quoted as a target around 180, though the useful version is relative: a cadence that drops sharply late in a race is a fatigue signal rather than a technique problem.

In PaceBrain terms, Cadence shows up whenever weekly logs are turned into features — the textbook definition is crisp, real training data is not, and the gap is where the modelling lives.
