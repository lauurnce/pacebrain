# PCA

Projecting data onto the orthogonal directions of greatest variance. Useful for compression and visualisation, but the components are linear combinations of every original feature, so interpretability is usually lost rather than gained.

Pca interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
