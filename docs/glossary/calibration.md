# Calibration

Whether predicted probabilities match observed frequencies — of everything given 0.7, roughly 70% should occur. A model can rank cases perfectly and still be badly calibrated, which matters whenever the probability itself is used rather than just the ordering.

Calibration interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
