# Imputation

Filling missing values with estimates so a model can consume the row. Whether a value is missing is often informative in itself, so recording a missingness indicator alongside the imputed value preserves signal that imputation alone discards.

Imputation interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
