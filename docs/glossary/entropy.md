# Entropy

A measure of uncertainty in a distribution, maximal when every outcome is equally likely. It sets the floor for lossless compression, which is the concrete reason it appears in loss functions rather than only in theory.

## See also

- [Logit](logit.md)

In PaceBrain, Entropy matters at exactly the boundary between baselines and fancier models — it is one of the knobs that decides whether added complexity earns its keep.
