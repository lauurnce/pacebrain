# Shakeout

A short very easy run the day before a race or after travel. It is about circulation and routine rather than fitness, since nothing meaningful can be gained the day before and something can be lost.

## See also

- [Long run](long-run.md)
- [Hill repeats](hill-repeats.md)

Shakeout interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
