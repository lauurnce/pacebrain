# Residual

The difference between a predicted and an actual value. The distribution of residuals says far more than any single error metric, since a consistent offset and random scatter of the same magnitude are very different problems.

The failure mode to watch with Residual is silent optimism: results improve on the validation set for reasons that will not survive contact with next month's data.
