# Maximum likelihood

Choosing the parameters that make the observed data most probable. Most standard losses are this in disguise — squared error assumes gaussian noise, cross-entropy assumes categorical — so the loss encodes a distributional assumption whether or not it is stated.

Maximum likelihood interacts strongly with dataset size here; behaviours that are footnote-level on benchmarks are headline-level on a few hundred athlete-weeks.
